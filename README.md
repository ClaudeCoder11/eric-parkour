# 3D Parkour

A Minecraft-style 3D parkour game that runs in the browser on both computer and phone.

## Play

From this folder:

```
python3 serve.py
```

Then open **http://localhost:8100**

(`serve.py` is a plain static server that also disables browser caching. Use it
rather than `python3 -m http.server`, or the browser will keep running old copies
of the code after you edit a file.)

On your phone (same wifi): find your Mac's IP with `ipconfig getifaddr en0`, then open
`http://THAT-IP:8100` in the phone browser and turn it sideways.

## Controls

**Computer**
| Key | Action |
|---|---|
| W A S D | Move |
| Space | Jump |
| Ctrl (or double-tap W) | Sprint |
| Shift | Sneak (won't fall off edges) |
| Mouse | Look (click the game first to lock the mouse) |
| V | Switch first-person / third-person |
| R | Respawn at last checkpoint |
| Esc | Pause |

**Phone**
Left thumb = joystick. Right side = drag to look. Buttons for jump, sprint, respawn,
and camera.

## Tests

Open **http://localhost:8100/tests.html** to run the physics tests. They check that a
sprint jump clears 4 blocks, a walk jump clears 3, the jump apex is 1.2522 blocks, and
that a fence is too tall to jump — the same numbers real Minecraft uses.

## Project layout

```
index.html        the game page
tests.html        physics test harness
serve.py          dev server (no-cache, so edits show up immediately)
lib/three.module.js   3D engine (vendored, pinned to r160, works offline)
src/              all game code, plain ES modules, no build step
src/levels/*.json the five levels — data, not code
STEPS.md          the build plan / progress checklist
```
